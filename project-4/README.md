## Project 4: Smart Home Management Panel

**Description:**
The final project of the 30-day JavaScript journey! This application simulates a smart home dashboard where users can toggle lights and adjust the temperature for different rooms.

**Technologies & Concepts Used:**
- **DOM Manipulation:** Built the entire dashboard structure dynamically using JavaScript.
- **Event Listeners:** Handled clicks for buttons to increase/decrease temperature and toggle lights.
- **State Management:** Managed the state of the home using a nested JavaScript object.
- **Web Storage API:** Persisted the home settings in `localStorage` so changes remain even after a page reload.
