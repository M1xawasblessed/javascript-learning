# Portfolio Project 2: Kanban Task Board

A feature-rich Kanban board web application built purely with **Vanilla JavaScript**, CSS3, and HTML5.

## Features
- **Drag and Drop Interface:** Move tasks seamlessly between To Do, In Progress, and Done columns.
- **Dynamic Task Creation:** Add new tasks with title, description, and priority level (Low, Medium, High).
- **Persistent State:** Uses `localStorage` to save all board data across browser sessions.
- **Task Deletion:** Easily remove completed or unwanted tasks.

## Concepts Applied
- HTML5 Drag and Drop API
- Web Storage API (`localStorage`)
- Modular DOM Manipulation
- Event Delegation and Handling
- Custom CSS Grid & Flexbox Layouts
